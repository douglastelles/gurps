# Aventuras

Esta pasta contém todas as aventuras, campanhas e encontros do jogo.

## Estrutura Sugerida

### Campanhas
- `campanhas/` - Campanhas em andamento
  - `campanha1/` - Primeira campanha
    - `sessao1.md` - Primeira sessão
    - `sessao2.md` - Segunda sessão
    - `notas.md` - Notas do mestre
  - `campanha2/` - Segunda campanha

### Módulos
- `modulos/` - Aventuras prontas
  - `modulo1.md` - Primeiro módulo
  - `modulo2.md` - Segundo módulo

### Encontros
- `encontros/` - Encontros específicos
  - `combate1.md` - Encontro de combate
  - `social1.md` - Encontro social
  - `exploracao1.md` - Encontro de exploração

## Formato de Sessão

```markdown
# Sessão X - [Título]

## Data
[Data da sessão]

## Participantes
[Lista de jogadores presentes]

## Resumo
[Resumo do que aconteceu]

## Pontos Importantes
- [Ponto 1]
- [Ponto 2]

## Próxima Sessão
[O que planejar para a próxima sessão]
```

## Formato de Encontro

```markdown
# [Nome do Encontro]

## Localização
[Onde acontece]

## Participantes
- [Lista de NPCs]
- [Lista de jogadores]

## Objetivos
- [Objetivo 1]
- [Objetivo 2]

## Desenvolvimento
[Como o encontro pode se desenvolver]

## Consequências
[O que pode resultar deste encontro]
```
