# Personagens

Esta pasta contém todas as informações relacionadas aos personagens dos jogadores e NPCs importantes.

## Estrutura Sugerida

### Por Jogador
- `jogador1/` - Pasta para cada jogador
  - `ficha.md` - Ficha completa do personagem
  - `background.md` - História e background
  - `equipamento.md` - Lista de equipamentos
  - `notas.md` - Notas do jogador

### Templates
- `templates/` - Templates de personagens
  - `guerreiro.md` - Template de guerreiro
  - `mago.md` - Template de mago
  - `ladino.md` - Template de ladino

### NPCs
- `npcs/` - Personagens não-jogadores
  - `aliados.md` - NPCs aliados
  - `inimigos.md` - NPCs inimigos
  - `neutros.md` - NPCs neutros

## Formato da Ficha

Use o seguinte formato para fichas de personagem:

```markdown
# Nome do Personagem

## Informações Básicas
- **Jogador**: [Nome do jogador]
- **Pontos**: [Total de pontos]
- **Idade**: [Idade]
- **Altura**: [Altura]
- **Peso**: [Peso]

## Atributos
- **ST**: [Força]
- **DX**: [Destreza]
- **IQ**: [Inteligência]
- **HT**: [Saúde]

## Vantagens
[Lista de vantagens]

## Desvantagens
[Lista de desvantagens]

## Perícias
[Lista de perícias]

## Equipamento
[Lista de equipamentos]
```
