# Documentos Originais

Esta pasta contém os PDFs originais do GURPS para consulta completa.

## 📚 PDFs Versionados com Git LFS

Os PDFs originais do GURPS são versionados usando **Git LFS** para permitir arquivos grandes (>100MB).

### PDFs Disponíveis
- `modulo-basico.pdf` - Módulo Básico do GURPS
- `GURPS Magia.pdf` - Módulo de Magias

### Organização
- Mantenha os PDFs originais aqui
- Use nomes descritivos
- Considere criar subpastas por tema se necessário

## Como Usar

1. **Consulta Completa**: Use os PDFs originais para informações detalhadas
2. **Referência Rápida**: Use os arquivos organizados nas outras pastas
3. **Ferramentas**: Use as ferramentas criadas para facilitar o uso

## Integração com Outras Pastas

- **`regras/`**: Contém versões organizadas das regras dos PDFs
- **`ferramentas/`**: Contém ferramentas baseadas nos PDFs
- **`recursos/`**: Contém referências extraídas dos PDFs

## Configuração Git LFS

Para configurar o Git LFS e versionar os PDFs, siga o guia em `CONFIGURAR-GIT-LFS.md`.
